### Структуры данных

- для хранения состояния игры используется объект Config(src/config.ts). Он позволяет за O(1) получать текущие настройки игры
- для хранения истории попыток используется список. Т.к. обновление происходит иммутабельно(т. е. создается новый объект), более эфективные с точки зрения добавления структуры данных(linked List, Balsnced Tree) не иммеют премущества. Списки же подерживаются js по умолчанию.
- evaluateGuess: при помощи reduce проходит по строке c секретом(secret) и сверяет её с предлженной попыткой(guess)
- countPossibleSecrets: рекурсивно вычисляется по формулулам:
  - countPossibleSecrets(length, base) = (base - length + 1) * countPossibleSecrets(length, base)
  - countPossibleSecrets(2, base) = base * (base - 1)

### Big O

- generateSecret: O(n)
- isValidGuess: O(n)
- evaluateGuess: O(n^2)
- countPossibleSecrets: worst:  O(n), mean: O(1)

Первые 3 функции проходят по массиву символов.
countPossibleSecrets производит n операций при перывом выполнении. Если значение уже было вычеслено, то вункция берет его из памяти, вместо того чтобы заново вычислять
evaluateGuess на каждой итерации reduce необходимо пройтись по всему массиву символов другой строки(O(n)). Учитывая что массив имеет длину n, получаем итоговую сложность O(n^2)
